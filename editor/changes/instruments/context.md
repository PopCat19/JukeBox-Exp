# Context

- `chip-wave.ts`, Implements undoable changes for chip wave and noise wave settings
- `effects.ts`, Implements undoable changes for instrument effects
- `envelopes.ts`, Implements undoable changes for envelope configuration
- `fm-operators.ts`, Implements undoable changes for FM synthesis operator settings
- `index.ts`, Barrel re-export of all instrument change classes
- `misc.ts`, Implements undoable changes for drumset, sustain, and fade settings
- `presets.ts`, Implements undoable changes for instrument presets and random generation
- `tone.ts`, Implements undoable changes for tone-related instrument settings
- `unison.ts`, Implements undoable changes for unison instrument settings
- `waveforms.ts`, Implements undoable changes for spectrum and harmonics waveforms
