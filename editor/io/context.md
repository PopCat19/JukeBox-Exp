# editor/io/

- `index.ts`, Barrel re-export of editor I/O modules
- `midi.ts`, Handles MIDI file parsing and export for song data interchange
- `midi-input.ts`, Manages real-time MIDI device input for live note playback
- `midi-parser.ts`, Parse MIDI binary data into JukeBox-Exp channel/pattern structures
- `song-recovery.ts`, Manages automatic song state recovery and backup persistence
