# UI Utilities

- `array-buffer-reader.ts` — Reads binary data from ArrayBuffer with position tracking
- `array-buffer-writer.ts` — Writes binary data to ArrayBuffer with position tracking
- `components.ts` — Shared UI component factory functions for prompt dialogs
- `html-wrapper.ts` — Wraps HTML input elements with undo-aware change tracking
- `index.ts` — Barrel re-export of editor UI utility modules
- `layout.ts` — Manages editor layout and responsive grid positioning
