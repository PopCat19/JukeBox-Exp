# editor/ui context

- `array-buffer-reader.ts` — Reads binary data from ArrayBuffer with multi-byte integer and string support
- `array-buffer-writer.ts` — Writes binary data to ArrayBuffer with multi-byte integer and string support
- `html-wrapper.ts` — Wraps HTML input elements with undo-aware change tracking
- `index.ts` — Barrel re-export of editor UI utility modules
- `layout.ts` — Manages editor layout modes and responsive CSS grid configuration
