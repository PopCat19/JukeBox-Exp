# Button Components

- `action-button.ts` — Text-labeled button for instrument operations (copy, paste, export, import)
- `clear-button.ts` — Compact × button for clearing input fields
- `delete-button.ts` — CSS class-based delete button for list rows (envelopes, etc.)
- `dropdown-button.ts` — Small toggle button with ▼ indicator for expanding dropdown menus
- `icon-button.ts` — Button styled via CSS class for icon-only controls (zoom, nav, etc.)
- `index.ts` — Barrel re-export of button variants
- `selector-button.ts` — Numeric selector button with no-underline styling
- `tab-button.ts` — Tab-style button for switching between prompt sections
- `toggle-button.ts` — Pair of mutually exclusive buttons for switching between two modes (e.g., simple/advanced)
