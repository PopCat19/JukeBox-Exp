# Context

- `index.ts` — Barrel re-export of prompt layout components
- `info-banner.ts` — Dismissible info/warning banners in prompts
- `input-row.ts` — Flex row for search input and action buttons in prompts
- `instructions.ts` — Helper text for keyboard shortcuts and usage hints
- `pane-container.ts` — Bordered flex row container for multi-pane prompt layouts
- `pane.ts` — Scrollable pane for use in multi-pane prompt layouts
- `prompt-components.ts` — Reusable components for prompt layouts
