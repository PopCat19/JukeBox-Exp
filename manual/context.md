# website/manual/

## Purpose

Static reference / documentation pages for the JukeBox site. All pages share
the same layout shell (defined in `subpages.css`), the same navigation
(generated by `scripts/generate-help-markdown.ts`), and the same typography
(`B612` for body, monospace for code blocks). No editor logic runs here.

## Files

- `subpages.css`, shared stylesheet: layout, typography, navbar, and
  page-specific overrides scoped under `body.page-*` classes
- `*.html`, one per topic (FAQ, credits, features, …)
- `keybinds.html`, keyboard shortcut reference (minimal shell, links to instructions)
- `leaderboard.html` + `leaderboard.js`, interactive community scores page
  (the only page with logic in this folder)

## Page structure

Every page uses semantic landmarks: `<header>` (shared nav), `<main>`,
`<footer>`. The nav block is delimited by `<!-- BEGIN NAV -->` and
`<!-- END NAV -->` markers, regenerated by `scripts/generate-help-markdown.ts`.
Each page sets `body class="page-<name>"` to scope its CSS overrides.

## Typography

All pages reference B612 from the self-hosted bundle:
`../assets/fonts/google/fonts.css`. The CSS file lives one level up so the
whole site shares a single font declaration source.
