# Channels

| Input | Action |
|---|---|
| `mouse` | Toggle channel mute |
| `mouse` | Rename, move, mute, solo, insert, delete channel |
| `Escape` | Close channel dropdown |
| `Enter` | Close channel dropdown |
| `ctrl+Q` | Open channel settings *(when not canPlayNotes)* |
| `shift+ctrl+Q` | Add external channel *(when not canPlayNotes)* |
| `G` | Open channel volume visualizer *(when not canPlayNotes)* |
