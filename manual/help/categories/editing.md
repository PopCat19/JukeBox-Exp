# Editing

| Input | Action |
|---|---|
| `Z` | Undo *(when not canPlayNotes)* |
| `shift+Z` | Redo *(when not canPlayNotes)* |
| `Y` | Redo (alternate) *(when not canPlayNotes)* |
| `X` | Cut notes *(when not canPlayNotes)* |
| `C` | Copy notes *(when not canPlayNotes)* |
| `V` | Paste notes *(when not canPlayNotes)* |
| `shift+V` | Paste instrument *(when not canPlayNotes)* |
| `ctrl+shift+V` | Paste pattern numbers *(when not canPlayNotes)* |
| `ctrl+D` | Duplicate patterns *(when not canPlayNotes)* |
| `Delete` | Reset pattern to 0 |
| `Enter` | Insert bars |
| `shift+Enter` | Insert bars before selection |
| `Backspace` | Delete bars |
| `ctrl+Enter` | Insert channel |
| `ctrl+Backspace` | Delete channel |
| `alt+Enter` | Add instrument to channel |
| `alt+Backspace` | Remove instrument from channel |
| `shift+C` | Copy instrument |
| `0-9` | Enter pattern number digits *(when not canPlayNotes)* |
| `mouse` | Start filter control point editing *(when _larger is true)* |
| `mouse` | Drag filter points, add/delete points |
| `touch` | Start touch filter editing |
| `Z` | Undo in filter editor *(only in larger filter editor)* |
| `Y` | Redo in filter editor *(only in larger filter editor)* |
| `mouse` | Start fade in/out editing |
| `mouse` | Drag fade in/out points |
| `touch` | Start touch fade editing |
| `mouse` | Change envelope target, type, waveform, or settings |
| `mouse` | Remove envelope |
| `mouse` | Copy envelope to localStorage |
| `mouse` | Paste envelope from localStorage |
| `mouse` | Start spectrum editing |
| `mouse` | Drag spectrum points |
| `touch` | Start touch spectrum editing |
| `mouse` | Start harmonics editing |
| `mouse` | Drag harmonics points |
| `touch` | Start touch harmonics editing |
| `mouse` | Set prospective change on slider input |
| `mouse` | Commit slider change to undo history |
| `mouse` | Reset slider to default on double-click *(only if doubleClickSliderReset pref enabled)* |
| `mouse` | Set prospective change on input box |
| `mouse` | Commit input box change to undo history |
| `wheel` | Increment/decrement number input by step on scroll *(only if enableScrollStep localStorage is true)* |
| `mouse` | Select toggle button option |
| `mouse` | Start algorithm node selection |
| `mouse` | Drag algorithm nodes, toggle modulation |
| `mouse` | Start custom chip waveform drawing |
| `mouse` | Draw custom chip waveform |
| `Shift` | Set patternEditor.shiftMode = true |
| `Shift` | Set patternEditor.shiftMode = false |
| `Ctrl` | Set patternEditor.controlMode = true |
| `Ctrl` | Set patternEditor.controlMode = false |
