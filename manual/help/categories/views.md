# Views

| Input | Action |
|---|---|
| `shift+/` | Open keyboard shortcuts help *(when not canPlayNotes)* |
| `mouse` | Filter shortcuts by search text |
| `Escape` | Close shortcuts prompt *(when prompt is open)* |
| `shift+ctrl+B` | Open beats per bar prompt *(when not canPlayNotes)* |
| `L` | Open bar count prompt *(when not canPlayNotes)* |
| `shift+L` | Open limiter settings *(when not canPlayNotes)* |
| `ctrl+E` | Open song EQ filter settings *(when not canPlayNotes)* |
| `shift+E` | Open instrument EQ filter settings *(when not canPlayNotes)* |
| `shift+N` | Open custom note filter settings *(when not canPlayNotes)* |
| `alt+E` | Toggle all envelope dropdowns open/closed |
| `alt+F` | Toggle all FM operator dropdowns open/closed |
| `W` | Open move notes sideways prompt *(when not canPlayNotes)* |
| `ctrl+E` | Open euclidean rhythm generator *(when not canPlayNotes)* |
| ``` | Open song recovery prompt *(when not canPlayNotes)* |
| `shift+`` | Create new blank song |
| `shift+U` | Open shortened URL for song |
| `mouse` | Zoom in pattern view |
| `mouse` | Zoom out pattern view |
| `Enter` | Save spectrum changes *(when spectrum prompt is open)* |
| `Space` | Toggle playback in spectrum editor *(when spectrum prompt is open)* |
| `Z` | Undo in spectrum editor *(when spectrum prompt is open)* |
| `Y` | Redo in spectrum editor *(when spectrum prompt is open)* |
| `Enter` | Save harmonics changes *(when harmonics prompt is open)* |
| `Space` | Toggle playback in harmonics editor *(when harmonics prompt is open)* |
| `Z` | Undo in harmonics editor *(when harmonics prompt is open)* |
| `Y` | Redo in harmonics editor *(when harmonics prompt is open)* |
| `Enter` | Save loop changes *(when not on a button)* |
| `Space` | Toggle playback *(when loop prompt is open)* |
| `mouse` | Start waveform zoom selection |
| `mouse` | Drag waveform zoom selection |
| `touch` | Start touch waveform zoom |
| `Escape` | Close current prompt *(when prompt is open)* |
