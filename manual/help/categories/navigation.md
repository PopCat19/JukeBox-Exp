# Navigation

| Input | Action |
|---|---|
| `ctrl+;` | Enter keyboard navigation mode |
| `H` | Previous bar (Shift extends selection) *(while keyboard navigation mode is active)* |
| `L` | Next bar (Shift extends selection) *(while keyboard navigation mode is active)* |
| `K` | Previous channel (Shift extends selection) *(while keyboard navigation mode is active)* |
| `J` | Next channel (Shift extends selection) *(while keyboard navigation mode is active)* |
| `Escape` | Exit keyboard navigation mode *(while keyboard navigation mode is active)* |
| `Up` | Navigate to previous channel |
| `Down` | Navigate to next channel |
| `Left` | Navigate to previous bar |
| `Right` | Navigate to next bar |
| `ctrl+Up` | Swap channel up |
| `ctrl+Down` | Swap channel down |
