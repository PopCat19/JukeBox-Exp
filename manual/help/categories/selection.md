# Selection

| Input | Action |
|---|---|
| `A` | Select all notes *(when not canPlayNotes)* |
| `shift+A` | Select current channel *(when not canPlayNotes)* |
| `Escape` | Clear selection *(when not Ctrl/Meta held)* |
| `shift+Up` | Extend box selection up |
| `shift+Down` | Extend box selection down |
| `shift+Left` | Extend box selection left |
| `shift+Right` | Extend box selection right |
