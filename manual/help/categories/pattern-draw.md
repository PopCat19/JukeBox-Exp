# Pattern Draw

| Input | Action |
|---|---|
| `F2` | Enter tracker composition mode |
| `Arrows+H+J+K+L` | Move tracker cursor (Shift extends time selection, Alt skips 2x, Ctrl+Alt 4x) *(while tracker composition mode is active)* |
| `Enter` | Place note (Shift adds a chord pitch) *(while tracker composition mode is active)* |
| `Delete+Backspace` | Remove note or chord pitch at cursor *(while tracker composition mode is active)* |
| `[+]` | Resize note tail (Shift scopes to note head) *(while tracker composition mode is active)* |
| `Escape` | Exit tracker composition mode *(while tracker composition mode is active)* |
| `mouse` | Start note editing/selection in pattern editor |
| `mouse` | Drag notes, resize (pin or full-height edge grab), move selection |
| `mouse` | End editing, record change |
| `touch` | Start touch note editing |
| `wheel` | Scroll to adjust hovered note length (nearest end) or default placement length on empty space *(when not mouseDown)* |
