# Live Input

| Input | Action |
|---|---|
| `mouse` | Start live note input on piano |
| `mouse` | Move cursor, play notes while dragging |
| `touch` | Start touch live input |
| `A-Z/0-9` | Play live note preview from keyboard *(when canPlayNotes (no Ctrl/Meta, correct CapsLock))* |
| `Any` | Release live pitches on key up |
| `mouse` | Translate MIDI note-on/off to performed pitches *(when MIDI enabled and this tab is MIDI handler)* |
| `ctrl+-` | Transpose selection down *(when not canPlayNotes)* |
| `ctrl+=` | Transpose selection up *(when not canPlayNotes)* |
| `ctrl+shift+-` | Transpose selection down one octave *(when not canPlayNotes)* |
| `ctrl+shift+=` | Transpose selection up one octave *(when not canPlayNotes)* |
