# Presets

| Input | Action |
|---|---|
| `T` | Next preset *(when not canPlayNotes)* |
| `shift+T` | Open preset selector *(when not canPlayNotes)* |
| `ctrl+R` | Random preset *(when not canPlayNotes)* |
| `ctrl+shift+R` | Random generated instrument *(when not canPlayNotes)* |
| `ctrl+alt+R` | Random generated instrument (alt) *(when not canPlayNotes)* |
| `shift+ctrl+I` | Copy instrument JSON to clipboard *(when not canPlayNotes)* |
| `shift+ctrl+alt+J` | Apply jummbox classic theme preset |
| `shift+ctrl+alt+S` | Apply slarmoosbox theme preset |
| `shift+ctrl+alt+T` | Apply violet verdant theme preset |
