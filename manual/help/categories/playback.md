# Playback

| Input | Action |
|---|---|
| `Space` | Toggle play/pause |
| `shift+Space` | Play from cursor and set loop to selection |
| `ctrl+Space` | Toggle recording |
| `ctrl+P` | Toggle recording and clear loop |
| `ctrl+F` | Go to start of song *(when not canPlayNotes)* |
| `shift+F` | Go to loop start *(when not canPlayNotes)* |
| `ctrl+H` | Play from current bar *(when not canPlayNotes)* |
| `ctrl+[` | Go to previous bar *(when not canPlayNotes)* |
| `ctrl+]` | Go to next bar *(when not canPlayNotes)* |
| `shift+S` | Mute channel *(when channel muting enabled)* |
| `S` | Solo channel *(when channel muting enabled)* |
| `ctrl+M` | Mute all channels (Shift to unmute) *(when channel muting enabled)* |
| `shift+ctrl+P` | Open song in player view |
