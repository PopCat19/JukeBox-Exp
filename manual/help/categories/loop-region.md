# Loop Region

| Input | Action |
|---|---|
| `mouse` | Start loop region drag |
| `mouse` | Drag loop points |
| `touch` | Start touch loop drag |
| `mouse` | Start loop handle drag |
| `mouse` | Drag loop handle |
| `touch` | Start touch loop handle drag |
| `ctrl+B` | Set loop to selection (or clear if already set) *(when not canPlayNotes)* |
