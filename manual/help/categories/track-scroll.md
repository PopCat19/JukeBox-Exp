# Track Scroll

| Input | Action |
|---|---|
| `mouse` | Click to scroll bar view left/right or drag handle |
| `mouse` | Drag scroll handle to navigate bars |
| `touch` | Touch drag to scroll bars |
| `mouse` | Click to scroll octave view or drag handle *(only for non-noise/non-mod channels)* |
| `mouse` | Drag octave handle to change visible range |
| `touch` | Touch drag to scroll octaves |
